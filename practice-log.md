# Practice log - tenses and mistakes

Goal: choose the right tense and form when speaking about my work (interview English).

The session process is described in `CLAUDE.md`.

## Next session

- Self-introduction for interviews (5-6 sentences), corrected the same way.
- Then round 4: keep **articles** in focus - *a / an* depends on the sound of the next word (*a new API, a QA
  engineer, an international company*); a profession always takes an article (*I'm a QA engineer*); second mention
  and unique things take *the* (*a bug ... the bug, the login form*).
- Mix in **prepositions**: *in* Python (language), *with* Playwright (tool), *for* 3 years, *since* last spring,
  *at* a company. And habit → Present Simple without *-ing* (*I usually test*).

## Tense choice - 4 questions

1. Habit / fact / duty → **Present Simple** (*I write test cases.*)
2. Happening now / temporary → **Present Continuous** (*I'm looking for a job.*)
3. Past:
   - specific time or a finished period (last week, on my last project) → **Past Simple** (*I wrote tests.*)
   - experience "as of today", time doesn't matter → **Present Perfect** (*I have never worked with C#.*)
   - started in the past and still going + for / since → **Present Perfect Continuous** (*I have been working in QA for 4 years.*)
4. Future: decision / promise → **will**; plan → **going to**.

Trap: Ukrainian "я працюю 4 роки" is NOT Present Simple → *I have been working ... for 4 years*.

Article rules: *a / an* depends on the next sound (*a new API, an API, a QA engineer, an international company*);
first mention → *a*, second mention → *the*; no article before *last / next*, languages and tools (*Python,
Playwright*). Prepositions: write code *in* Python, test *with* Playwright, work *at* a company.
