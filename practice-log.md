# Practice log - tenses and mistakes

Goal: choose the right tense and form when speaking about my work (interview English).

The session process is described in `CLAUDE.md`.

## Next session

  tense rules from session 2: since / for + still → *have been + -ing*; "now" → *is / are + -ing*; plan →
  *going to*.
- After that: self-introduction for interviews (5-6 sentences), corrected the same way.

## Tense choice - 4 questions

1. Habit / fact / duty → **Present Simple** (*I write test cases.*)
2. Happening now / temporary → **Present Continuous** (*I'm looking for a job.*)
3. Past:
   - specific time or a finished period (last week, on my last project) → **Past Simple** (*I wrote tests.*)
   - experience "as of today", time doesn't matter → **Present Perfect** (*I have never worked with C#.*)
   - started in the past and still going + for / since → **Present Perfect Continuous** (*I have been working in QA for 4 years.*)
4. Future: decision / promise → **will**; plan → **going to**.

Trap: Ukrainian "я працюю 4 роки" is NOT Present Simple → *I have been working ... for 4 years*.

| Category | S1 | S2 | Total | Typical example → correct |
|---|---|---|---|---|
| Articles | 3 | 5 | **8** | *critical bug* → *a critical bug*; *a API* → *an API*; *the next month* → *next month* |

| Tense choice | 2 | 4 | **6** | *I worked ... since 2022* → *I have been working*; *the team have been testing* (now) → *is testing* |

| Irregular verbs | 1 | 0 | **1** | *writed* → *wrote / written* |
