# English practice (interview English for QA)

Practice with Claude: translate Ukrainian sentences about QA work into English, get corrections, track mistakes by
category until tense choice and articles stop being a problem.

## How to continue on any device

1. Open this repository in Claude Code - locally, or on the web at https://claude.ai/code.
   (One-time setup, already done: the Claude GitHub App is installed with access to this repo -
   https://github.com/settings/installations.)
2. Write **"попрактикуємо англійську"**.

Claude follows `CLAUDE.md`: reads `practice-log.md` (statistics + next session focus), runs a round of 8 sentences,
then logs the results and pushes them back here.

## Files

| File | What's inside |
|---|---|
| `CLAUDE.md` | Rules for Claude: how a session and a round work, how to log results |
| `practice-log.md` | Tense-choice rules, mistake statistics, next session focus, log of all rounds |
